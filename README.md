# Labs Overview

Welcome to the repository. This project contains documentation for various C programming and compilation tasks executed in an Ubuntu/WSL environment.


## Task Documentation

* lab 1: C Compilation Pipeline (./os-programming/lab1.md)** - Details on preprocessing, assembly, compiling and code execution.
* Lab 2 - Task 1: Process Creation & Execution (./os_programming/lab2.md)** - C process timing using `sleep()`, execution, and process table filtering using `ps aux`
* Lab 2 - Task 2: Process Identifiers (PID & PPID)(./os_programming/lab2.md)** - Retrieving process attributes using `getpid()` / `getppid()` and process inspection using `ps -p`.

## Requirements:
* Linux (Ubuntu 20.04/22.04 LTS) or Windows Subsystem for Linux
* GCC Compiler
* Linux / WSL Environment
